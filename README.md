# 🧠 Simon Game

An interactive memory game built with HTML, CSS, JavaScript, and jQuery. Test your memory by repeating an increasingly long sequence of colors and sounds.

## 🎮 Live Demo

**[Play Simon Game](https://harshitprajapati07.github.io/Simon-game/)**

## ✨ Features

- Interactive color sequence gameplay
- Sound effects for game interactions
- Increasing difficulty as you progress
- Keyboard and mouse interaction, if supported by the implementation
- Responsive design, if supported by the implementation

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- jQuery

## 🚀 Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start playing!

## 📁 Project Structure

- `index.html` — Game structure
- `styles.css` — Styling
- `game.js` — Game logic
- `sounds/` — Game sound effects
